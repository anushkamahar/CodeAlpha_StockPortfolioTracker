# Stock Portfolio Tracker

This is a simple stock portfolio tracker made using Python.I created this project as part of my CodeAlpha Python Programming Internship. 

## About the Project

The program allows the user to enter stock names and their quantities. It uses predefined stock prices to calculate the investment for each stock and then shows the total investment.

The portfolio details are also saved in a text file named `portfolio.txt`.

## Features

* Uses predefined stock prices
* Takes stock name and quantity from the user
* Calculates the investment for each stock
* Calculates the total investment
* Allows the user to add multiple stocks
* Saves the portfolio details in a text file

## Stocks Available

The program currently has these stocks:

* AAPL
* TSLA
* GOOGL
* AMZN
* MSFT

## Technologies Used

* Python
* Dictionary
* Lists
* Loops
* Conditional statements
* File handling

## How to Run

Make sure Python is installed.

Run the following command in the project folder:

```bash
python StockPortfolioTracker.py
```

Enter the stock name and quantity when asked.

After finishing, the total investment will be displayed and the portfolio will be saved in `portfolio.txt`.
